### RAG Backend

This project implements a **Retrieval-Augmented Generation (RAG) backend** for answering questions using information collected from L&T's publicly available webpages and annual reports. The pipeline downloads and parses both HTML webpages and PDF documents, extracts their text, cleans and preprocesses the content, and divides it into overlapping chunks using LangChain's `RecursiveCharacterTextSplitter`. Each chunk is stored along with its source filename and URL as metadata. The chunks are then converted into vector embeddings using the `sentence-transformers/all-MiniLM-L6-v2` model and persisted in a **ChromaDB** vector database for efficient similarity search. For each user query, the system generates a query embedding and retrieves the most semantically relevant chunks from ChromaDB, after which a **CrossEncoder (`ms-marco-MiniLM-L6-v2`)** re-ranks the retrieved candidates to improve relevance. The highest-ranked content is formatted into plain-text context and supplied to an **Azure OpenAI** model, which generates the final answer based on the retrieved information. The project also includes chat logging that records the user's original query, retrieved context, prompts, and generated responses for later review and debugging.
